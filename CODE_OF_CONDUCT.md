# Sonaris Code of Conduct

We aim to make participation respectful, constructive, and accessible.

## Expected conduct

- Discuss ideas and evidence with care; critique work without attacking people.
- Welcome questions and contributors with different backgrounds and experience.
- Respect privacy, attribution, and the confidentiality of survey data.
- Accept constructive feedback and correct mistakes openly.

Harassment, discriminatory abuse, threats, unwanted sexual attention, doxxing, and deliberately disruptive behavior are not acceptable in project spaces.

## Scope and enforcement

These expectations apply to repository issues, pull requests, and other project-managed discussions. Maintainers may edit or remove inappropriate content, close disruptive discussions, or restrict participation according to the severity and repetition of the behavior.

Raise concerns with the repository maintainer through an available GitHub contact channel. Do not post private details publicly. If private contact is unavailable, use GitHub's reporting tools for platform abuse. Reports should be handled with discretion and without retaliation.
